# دليل استخدام صفحة مستخرج الجزاءات

## نظرة عامة
صفحة مستخرج الجزاءات هي صفحة رسمية قابلة للطباعة والتصدير تعرض جميع الجزاءات المسجلة لفرد معين.

## كيفية الوصول إلى الصفحة

### الطريقة الأولى: من صفحة سجل الجزاءات
1. انتقل إلى **الجزاءات** > **السجلات**
2. في عمود "الإجراءات"، اضغط على الزر الأزرق (أيقونة الملف) بجانب أي سجل جزاء
3. سيتم فتح صفحة مستخرج الجزاءات لهذا الفرد

### الطريقة الثانية: مباشرة عبر الرابط
```
/penalties/extract/<employee_id>/
```
مثال: `/penalties/extract/123/` لعرض جزاءات الفرد رقم 123

## محتويات الصفحة

### الترويسة الرسمية
- وزارة الداخلية
- قطاع التدريب
- الإدارة العامة للتدريب
- إدارة موسيقات الشرطة

### عنوان المستند
**مستخرج جزاءات**

### بيانات الفرد
الدرجة / الاسم الكامل للفرد

### جدول الجزاءات
يحتوي على ثلاثة أعمدة:
1. **مسلسل**: رقم تسلسلي تلقائي
2. **المخالفة**: وصف المخالفة المرتكبة
3. **الجزاء الموقع عليه**: نوع الجزاء ومقداره (إن وجد)

## الميزات المتاحة

### 1. الطباعة
- اضغط على زر **طباعة** في أعلى الصفحة
- أو استخدم اختصار لوحة المفاتيح `Ctrl + P`
- سيتم إخفاء الأزرار والعناصر غير الضرورية تلقائياً عند الطباعة

### 2. التصدير إلى Excel
- اضغط على زر **تصدير Excel**
- سيتم تحميل ملف Excel يحتوي على:
  - الترويسة الرسمية
  - بيانات الفرد
  - جدول الجزاءات كاملاً
- اسم الملف: `مستخرج_جزاءات_[اسم الفرد]_[التاريخ].xlsx`

### 3. الرجوع
- زر **رجوع** للعودة إلى صفحة سجل الجزاءات

## ملاحظات مهمة

1. **عدم وجود جزاءات**: إذا لم يكن للفرد أي جزاءات مسجلة، سيظهر رسالة "لا توجد جزاءات مسجلة لهذا الفرد"

2. **الترتيب**: يتم عرض الجزاءات مرتبة حسب تاريخ الجزاء من الأقدم إلى الأحدث

3. **إجمالي الجزاءات**: يظهر في أسفل الصفحة العدد الإجمالي للجزاءات

4. **التنسيق للطباعة**: الصفحة مصممة بحجم A4 وجاهزة للطباعة مباشرة

## المسار في الكود

- **View**: `penalties/views.py` - `PenaltyExtractView`
- **Template**: `penalties/templates/penalties/penalty_extract.html`
- **URL**: `penalties/urls.py` - `penalty_extract`
- **اسم URL**: `penalties:penalty_extract`

## مثال على الاستخدام في القوالب

```django
<!-- رابط لمستخرج جزاءات فرد معين -->
<a href="{% url 'penalties:penalty_extract' employee.id %}">
    عرض مستخرج الجزاءات
</a>
```

## التحسينات المستقبلية المقترحة

1. إضافة فلترة حسب الفترة الزمنية
2. إضافة إمكانية التوقيع الإلكتروني
3. إضافة رقم القرار وتاريخه لكل جزاء
4. إضافة إمكانية إرسال المستخرج عبر البريد الإلكتروني
5. إضافة شعار الوزارة في الترويسة
